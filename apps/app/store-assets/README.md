# Store listing assets

Generated and reference files for **App Store Connect**, **Google Play Console**, and in-repo publishing docs.

Full pipeline guide: [`docs/STORE_ASSETS.md`](../../docs/STORE_ASSETS.md).

## Directory layout

```
store-assets/
├── captures-native/          # Full native matrix (Maestro) — optional to commit
│   ├── android/<locale>/<theme>/<scene>.png
│   └── ios/<locale>/<theme>/<scene>.png
├── captures/<locale>/        # Studio inputs (7 images per locale)
├── ios/screenshots/          # Final App Store PNGs
├── android/screenshots/      # Final Play Store PNGs
└── android/feature-graphic/  # Play feature graphic 1024×500
```

## Localized marketing screenshots (3 languages)

Designed store screenshots (advertisement-style, dark brand theme matching the marketing site) are generated by **`tools/screenshot-studio`** for all product locales (`en`, `ar`, `ur`):

| Asset | Path |
|-------|------|
| iOS 6.9" (1320×2868) | `ios/screenshots/6.9-inch/<locale>/NN-<scene>.png` |
| iOS 6.5" (1242×2688) | `ios/screenshots/6.5-inch/<locale>/NN-<scene>.png` |
| iPad 13" (2064×2752) | `ios/screenshots/13-inch/<locale>/NN-<scene>.png` |
| Play phone (1080×1920) | `android/screenshots/phone/<locale>/NN-<scene>.png` |
| Play feature graphic (1024×500) | `android/feature-graphic/<locale>.png` |
| Play 7" tablet (1200×1920 / 1920×1200) | `android/screenshots/tablet-7-inch/{portrait,landscape}/<locale>/NN-<scene>.png` |
| Play 10" tablet (1600×2560 / 2560×1600) | `android/screenshots/tablet-10-inch/{portrait,landscape}/<locale>/NN-<scene>.png` |

Scenes per locale: `01-home`, `02-salah`, `03-qaza`, `04-library`, `05-privacy`, `06-offline`, `07-more`.

**Regenerate:**

```bash
pnpm screenshots:android              # or screenshots:ios — native captures
pnpm seed:screenshot-studio           # refresh deck copy
pnpm sync:screenshot-captures         # copy captures into editor
pnpm dev:screenshot-studio            # export each device tab in UI
pnpm distribute:screenshot-exports    # copy exports here
```

See also `tools/screenshot-studio/README.md`.

## Raw app captures (inputs to the studio)

Seven images per locale before exporting marketing frames:

```
captures/<locale>/
  home.jpg
  tracker.jpg
  qaza.jpg
  zikr.jpg
  quran.jpg
  settings-privacy.jpg
  settings-sync.jpg
```

**Automated:** `pnpm screenshots:android` or `pnpm screenshots:ios` seeds demo data via Maestro, captures all screens, and copies dark marketing aliases into `captures/<locale>/` (see `apps/app/scripts/screenshots/lib/config.mjs` → `STUDIO_ALIASES`).

**Manual:** run the app on iOS Simulator or Android emulator at native resolution in dark mode; switch locale before each batch. JPEG or PNG accepted.

| Studio file | App screen |
|-------------|------------|
| `home.jpg` | Home tab |
| `tracker.jpg` | Salah tracker (or status sheet variant) |
| `qaza.jpg` | Qaza planner |
| `zikr.jpg` | Adhkar / zikr |
| `quran.jpg` | Qur'an reader |
| `settings-privacy.jpg` | Settings → offline data |
| `settings-sync.jpg` | Settings → backup |

## Native capture archive

`captures-native/` holds the full matrix: every documented screen × `en`/`ar`/`ur` × `light`/`dark` × platform. Useful for QA, design review, and picking alternate marketing crops. Generated by [`apps/app/scripts/screenshots/`](../scripts/screenshots/README.md).

Device sizes, locale list, capture filenames, and slide scene names are centralized in `@munib-tracker/store-screenshots` (`packages/store-screenshots`).
