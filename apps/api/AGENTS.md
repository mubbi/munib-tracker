# Munib Tracker API — Agent Guide

NestJS backend for cloud sync, social login, and future server-side features.

## Quick reference

| Item | Value |
|------|-------|
| **Path** | `apps/api` |
| **Dev command** | `pnpm dev:api` |
| **Default port** | `3001` (marketing-web uses `3000`) |
| **Base path** | `/api/v1` |
| **OpenAPI docs** | `http://localhost:3001/docs` |

## Stack

- **NestJS 11** + **TypeScript 6** + **Express**
- **PostgreSQL** via **TypeORM** (`@nestjs/typeorm`)
- **OpenAPI** exported to `@munib-tracker/api-contract` → Orval SDK in `@munib-tracker/api-client`
- **Webpack + SWC** monorepo build
- **Biome** lint, **Vitest** tests
- **date-fns** for API datetime parsing

## Client integration

Apps consume the API through `@munib-tracker/api-client`:

- Native **`fetch`** (no axios) via Orval [fetch client](https://orval.dev/docs/guides/fetch)
- [**TanStack Query**](https://tanstack.com/query/latest/docs/framework/react/installation) hooks generated by Orval
- `date-fns` helpers at `@munib-tracker/api-client/datetime`

Regenerate after API changes:

```bash
pnpm generate:api
```

## Modules

| Module | Purpose |
|--------|---------|
| `health` | Liveness probe at `GET /api/v1/health` |
| `auth` | Guest sessions, OAuth callbacks, account linking |
| `sync` | Pull/push cloud sync (last-write-wins) |

## Environment

Copy `.env.example` to `.env` (or `.env.local`) in this directory:

```bash
cp apps/api/.env.example apps/api/.env
```

Key variables: `PORT`, `JWT_SECRET`, `CORS_ORIGINS`, OAuth provider IDs.

## Commands

```bash
pnpm dev:api                  # watch mode
pnpm --filter api build       # production build
pnpm --filter api test        # unit tests
pnpm --filter api test:e2e    # e2e tests
pnpm --filter api check-types
```

## Conventions

- Global prefix: `api/v1`
- Validation: `ValidationPipe` with `class-validator` DTOs
- Swagger decorators on all public endpoints
- In-memory stores for auth/sync until a database layer is added (Phase 8)
