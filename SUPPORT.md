# Support

Munib Tracker is a free, non-commercial worship companion.

## No sponsorship, funding, or donations

**We do not currently accept sponsorship, funding, or donations.** Do **not** send
money to anyone claiming to collect funds on behalf of Munib Tracker. There is no
official Patreon, GitHub Sponsors, crypto wallet, or payment link for this project
at this time. Contributions of **code, docs, translations, and content corrections**
are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).

| Need | Where to go |
|------|-------------|
| Product questions / feedback | [Contact form](https://munibtracker.app/contact) |
| FAQ | [https://munibtracker.app/faq](https://munibtracker.app/faq) |
| Content accuracy (Qur'an, hadith, duas) | In-app report flow, contact form, or a [GitHub content issue](https://github.com/mubbi/munib-tracker/issues/new?template=content_accuracy.yml) |
| Bugs & feature requests | [GitHub Issues](https://github.com/mubbi/munib-tracker/issues) |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |
| License / source-available terms | [https://munibtracker.app/open-source](https://munibtracker.app/open-source) · [`LICENSE`](LICENSE) · [`NOTICE`](NOTICE) |
| Security vulnerabilities | [SECURITY.md](SECURITY.md) — **not** public issues |
| Credits & data sources | [https://munibtracker.app/credits](https://munibtracker.app/credits) |

There is no paid support SLA. Maintainers triage community issues as capacity allows.
