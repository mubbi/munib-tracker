# Platform feature matrix

Status: Phase 2 audit complete (2026-11-25) — fixes tracked in docs/ui-ux-progress.md

Which features exist on which surface today, and how far each surface should go. Evidence and findings: [`cross-platform-ui-ux-audit.md`](cross-platform-ui-ux-audit.md) (E-ids) and [`ui-ux-audit.md`](ui-ux-audit.md). Design rules per surface: [`platform-ux-guidelines.md`](platform-ux-guidelines.md). Support matrix by device: [`DEVICES.md`](DEVICES.md).

"Current" is read from code, gating flags and docs — **not from running the app on any device**. TV availability in particular comes from the registry `notOnTv` filters and per-screen gates.

## Legend

| Mark | Current availability |
| ---- | -------------------- |
| ✅   | Available            |
| ◐    | Partial              |
| —    | Absent               |

| Recommended level | Meaning                                                                            |
| ----------------- | ---------------------------------------------------------------------------------- |
| Full              | Every capability of the feature, laid out for the surface                          |
| Adaptive          | Same capability, different layout or input model (large type, D-pad, wide columns) |
| Simplified        | Core action only; entry-heavy, private or secondary parts stay on the phone        |
| Glanceable        | One fact, at most one action (complication, tile, widget)                          |
| Not suitable      | Do not build; the surface cannot do it well or it would truncate religious text    |

Columns: **Web** (desktop, mobile browser, PWA) · **iOS** (iPhone, iPad) · **Android** (phone, tablet) · **TV** (Apple TV, Android TV, Fire TV) · **Apple Watch** (app + complications) · **Wear OS** (tiles + the tasbeeh counter app).

## Reading the matrix

| Surface           | Verdict                                                                                                                                                    |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web, iOS, Android | Feature-complete. Work here is quality (see [`ui-ux-audit.md`](ui-ux-audit.md)), not scope.                                                                |
| TV                | Over-served: nearly the whole app is exposed. Trim to tracking, times, reading, listening and learning; hide finance (decided) and keep vault tools off.   |
| Apple Watch       | Under-served on its two strengths: next Salah at a glance and tasbeeh counting. Fix E-31 to E-34 before adding anything.                                   |
| Wear OS           | Tiles only at audit time, with lost and accidental marks (E-37, E-38). The tasbeeh counter app is the first real app surface; complications remain absent. |
| Widgets           | Broad coverage (12 kinds per platform). Gaps are polish: rendering modes, picker metadata, configuration (E-17, E-19, E-21 to E-23).                       |
| Live Activities   | Implemented; add the small family for Watch Smart Stack and CarPlay (E-18).                                                                                |
