# Proof log: Duroods & salawat (D11)

- **Feature:** the Duroods screen (`apps/app/src/app/duroods/`) — salawat wordings to recite, and reports on the virtue of sending salah upon the Prophet ﷺ, each with an exact citation and published grade, a reader (`/duroods/[id]`) and the full source narration.
- **Review:** AI proof-backed review (D11), 2026-11-27.
- **Rule applied:** every Arabic wording, English meaning, citation and grade is cut verbatim out of a pinned open dataset by `apps/app/scripts/build-data/build-duroods.mjs`. The builder only holds the _mapping_ (record + start/end markers); each marker must be found in the record or the build fails. Only narrations graded sahih or hasan ship (`assertAcceptedGrade`). Output: `packages/shared/src/content/duroods.ts` (`DUROOD_CONTENT_VERSION` 7) and `apps/app/assets/data/hadith/durood-sources.json` (verbatim narrations + ur/id/tr/bn/fr/ru dataset translations).

**Numbering.** Citations use the conventional numbers: Bukhari, Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah = the API `hadithnumber`; **Muslim = Abdul Baqi** (`floor(arabicnumber)`), while the API record is fetched by its sequential `hadithnumber` (e.g. Muslim 405 = API 907). **Grades.** Bukhari and Muslim carry no per-hadith grade in the dataset (every hadith in them is sahih) and are shown as "Sahih". Sunan grades are Al-Albani's as published in the edition; other graders are listed below where they differ.

## 4. Excluded or limited (and why)

- **Nasa'i 1290 / 1291 (Talhah ibn 'Ubaydullah):** Sahih, but the dataset's English for both is a copy of the 1285 template (it renders "fil-'alamin", which the Arabic lacks). Excluded until a matching translation exists — no hand translation.
- **Abu Dawud 981 (an-Nabiyy al-Ummi):** Hasan, but only a partial wording («قولوا اللهم صل على محمد النبي الأمي وعلى آل محمد») pointing back to the full report; excluded so no item is a fragment.
- **Abu Dawud 982, Ibn Majah 906:** graded Daif — excluded.
- **Ka'b variants (Bukhari 4797/6357, Muslim 406, Abu Dawud 976/978, Tirmidhi 483, Nasa'i 1287–1289, Ibn Majah 904):** the same report with small wording differences; not listed separately (Muslim 406 and Abu Dawud 976 are cited on `durood-ibrahim`).
- **`durood-salli-ala` meaning** ("May Allah send blessings and peace upon him.") is the previously shipped rendering of the formula; no dataset translates the bare formula. Kept because the id may be saved; flagged for a dataset source.
- **Per-locale meaning of the formulas:** only Bengali (ThelightHub / Hisnul CSV, matched by Arabic) exists for three items. Other locales read the full narration in their language from the source card (dataset editions ur/id/tr/bn/fr/ru); no locale text was written for scripture (D45).

## 5. Audio

- Only Hisnul Muslim rows whose normalized Arabic is **identical** to the item's wording attach audio, and the pinned URL must answer a `HEAD` request with an audio content type during the build (cached in `.cache/*.head`). Result: `durood-ibrahim` (53hm), `durood-abu-humayd` (54hm), `durood-short` (98hm).
- The fuzzy prefix matcher used for adhkar is **not** run on duroods (a wrong recording is worse than none).
- No other documented open audio source (`docs/FREE_OPEN_SOURCE_DATA.md` §9.4: GTAF / khDev01 / Seen-Arabic) has recordings beyond the same Hisnul Muslim corpus. Items without a recording get the device voice (`ReadingTtsButton`, not on TV) in the reader.
