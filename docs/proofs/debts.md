# Proof log: Debts & trusts record (NF-3.8, Dayn / Amanah)

- **Feature:** a private record of loans I owe / am owed, trusts held / given, repayments, forgiveness and vows, with a read-only religious-obligations summary that feeds the wasiyyah (NF-3.9).
- **Code:** `apps/app/src/lib/debts/*` (rules, merge, obligations, statement), `apps/app/src/components/debts/*`, routes `apps/app/src/app/debts/*`, reminders `apps/app/src/lib/notifications/vault-reminders.ts`. Copy: `apps/app/scripts/i18n/debts-i18n.json` (`debts.*`).
- **Storage:** vault document `debts` only (D2 / §4.2) — AES-256-GCM at rest, opt-in E2E sync; see `docs/proofs/vault.md`.
- **Review:** AI proof-backed review (D11), 2026-11-23. Scripture is cited by reference only; the copy paraphrases and never quotes ayah or hadith text.

## 0. How refs were checked

- **Qur'an:** against the bundled corpus `apps/app/assets/data/quran/translation/en-pickthall/<surah>.json` (ayah exists, meaning matches the claim).
- **Hadith:** against the corpus the app renders, `fawazahmed0/hadith-api@1` (`cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/eng-<collection>/<n>.json`, fetched 2026-11-23). Bukhari, Abu Dawud and Tirmidhi corpus numbers equal sunnah.com. **Sahih Muslim** is cited in print (Abd al-Baqi) numbering; the corpus number differs and was paired via its `arabicnumber` field.

## 3. Privacy (plan §2.4)

- Notification text is generic: "Personal reminder" / "A payment is due. Open the app to see the details." — no counterparty, amount or count (`vault-reminders.test.ts`).
- Reminder inputs leave the vault as **dates only** (`vault-reminder-options.ts`).
- The statement export (D30) renders a PDF with `expo-print` into the cache only while the share sheet is open, then deletes it (native; a binary without `expo-print` shares a temporary HTML file the same way); on web it prints from an in-memory iframe.
- Document photo (`documentUri`, plan L1595; added 2026-11-24): optional. The image bytes are sealed with the vault DEK (AES-256-GCM, `MVF1` file format, AAD binds the file id) into `<documents>/vault-files/` (native) or IndexedDB `munib-vault-files` (web). The debt record stores only a `vault-file:<id>` reference; the file is **never synced or backed up** (the card says so; another device shows "added on another device"). Size cap 2 MB after the picker's compression (web downscales via canvas; no image-manipulation dep is bundled, so native relies on the picker's JPEG quality). Re-encrypted when the vault adopts another key; wiped when the key is deleted (Reset app data, vault "start fresh"); deleted with its debt. Hidden on TV. Tests: `lib/debts/debt-photo.test.ts`.
- Hidden on TV (shared screen).

## 4. Excused periods

**D31 (owner decision, 2026-11-24):** debt due-date reminders keep firing during excused periods, because a due date is a commitment to another person rather than a worship nudge (text stays generic, no amounts). Wasiyyah review reminders still pause while `activeExcusedReason` is set (plan §2.5).
