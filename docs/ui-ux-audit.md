# UI/UX audit — product app (`apps/app`)

Status: Phase 2 audit complete (2026-11-25) — fixes tracked in docs/ui-ux-progress.md

Consolidated findings for the Expo product app (iOS, Android, Web, Apple TV, Android TV). Per-platform and companion-surface detail: [`cross-platform-ui-ux-audit.md`](cross-platform-ui-ux-audit.md). Feature suitability per surface: [`platform-feature-matrix.md`](platform-feature-matrix.md). Target system the fixes move towards: [`design-system.md`](design-system.md), [`cross-platform-design-system.md`](cross-platform-design-system.md), [`platform-ux-guidelines.md`](platform-ux-guidelines.md).

Unless a path starts with `packages/`, `docs/`, `targets/` or `plugins/`, locations are relative to `apps/app/src/`. Line numbers are from the working tree on 2026-11-25 (about 680 uncommitted changes) and will shift.

## Scope and method

| Item             | Detail                                                                                                                                                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| What was audited | `apps/app/src` routes, components, tokens, i18n catalog (`en.json`), plus native companions (see the cross-platform audit)                                                                                                                                 |
| How              | **Code reading only**, by seven review slices (A–G) plus a step-0 pass on the settings editors (S). Drift counts come from regex sweeps over 888 non-test `.tsx` files; contrast ratios are computed from token hex values with the WCAG formula           |
| Not done         | **Nothing was verified on a device, simulator, TV, watch, screen reader or browser.** Every visual, focus, Dynamic Type, RTL and contrast-on-screen claim is an inference from code. Items marked "verify" in the source slices still need a runtime check |
| Screenshots      | A baseline web capture was attempted and **failed**: none of the 67 images shows app UI (see [Before screenshots](#before-screenshots)). No visual finding in this document comes from a screenshot                                                        |
| Locales          | Only English copy was reviewed; the other 23 catalogs and real RTL rendering were not                                                                                                                                                                      |
| Delegation       | Slice B findings B-21 onward, G batches 1–4 and slice S were read by delegated reviewers and only spot-checked by a lead (B-21, B-22, B-80, G-01, G-52, G-64 re-read)                                                                                      |

## Coverage statement

Route files under `apps/app/src/app` (non-test `.tsx`): **285**.

| Read depth  | Routes | Share | Meaning                                                                                                                                                                                     |
| ----------- | ------ | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Full        | 226    | 79%   | Render body and StyleSheet read (import blocks skimmed). Includes slice B's 42 routes (3 by the lead, 39 by delegated reviewers) and the 21 settings wrappers/redirects confirmed in step 0 |
| Render path | 57     | 20%   | Route and its main component read on the render path by slice C or D; styles and secondary branches not necessarily read                                                                    |
| Partial     | 1      | 0%    | `qibla/index.tsx` — two halves read by two different slices                                                                                                                                 |
| Not read    | 1      | 0%    | `+html.tsx` (document shell; only its focus-ring CSS was read by slices E and F)                                                                                                            |

So **99% of route files have a verdict from a reviewer who read at least the render path; 79% were read in full.** This is route-level coverage only. Below the route level it is lower and uneven:

## Application inventory

### Navigation architecture

| Layer         | Implementation                                                                                                                                | Notes                                                                                                                                                                                                                                                 |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root          | expo-router stack (`components/app-stack.tsx`) under the provider tree in `app/_layout.tsx`                                                   | Gates in order: version gate, onboarding gate, PIN lock gate, error boundary. `presentation: "modal"` is used only for login                                                                                                                          |
| Tabs          | `(tabs)`: Home (`index`), Tracker, Library, Settings                                                                                          | iPhone/Android phone: system `NativeTabs` (`app-tabs.tsx`). Narrow web: bottom bar (`app-tabs.web.tsx`). ≥768pt tablets and TV: custom 232pt rail (`app-tabs-wide.tsx`). Web also has a global rail beside the root stack (`web/web-global-rail.tsx`) |
| First run     | `(onboarding)/intro` → `(onboarding)/setup` (5 steps + summary) → tabs; `(auth)/login` optional (guest-first; QR pairing on TV via `tv-pair`) | Up to 12 screens (D-31)                                                                                                                                                                                                                               |
| Library       | `lib/library-menu.ts`: 77 destinations in five sections (Track 17, Read 8, Supplicate 5, Learn 28, More 15)                                   | Flat index (C-05); its filter does not reach universal search (C-06)                                                                                                                                                                                  |
| Settings      | Registry (`lib/settings/`): 5 clusters, 14 groups, search, deep links with scroll-to-row, master–detail on wide screens, per-section reset    | Strongest IA in the app; max depth 3                                                                                                                                                                                                                  |
| Cross-cutting | Universal `/search`; deep link `/mark-current`; sheets and dialogs on one `Sheet` primitive; toasts via `ToastProvider`                       | 10 dialog/sheet patterns in total, 3 of them outliers (raw `Modal`, `Alert.alert`, absolute overlays)                                                                                                                                                 |
| Wide layouts  | `ScreenLayout` width tiers (1024 / 1600) and per-screen two-pane layouts                                                                      | Breakpoints are literals: 900 / 1024 / 1200 and seven aside widths (A-26 = B-47)                                                                                                                                                                      |
