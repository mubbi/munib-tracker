> **Tip:** The `Promotional Text` field can be updated at any time without submitting a new app version — use it for Ramadan messaging, Eid announcements, or feature highlights.

## How to submit

1. Open [App Store Connect](https://appstoreconnect.apple.com) → select your app → **App Information**
2. In the sidebar, choose a language
3. Copy-paste each field into the matching input (App Subtitle, Promotional Text, Description, What's New, Keywords, URLs)
