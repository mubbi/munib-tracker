## How to read a task

| Field      | Values                                                                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID         | `P<phase>-<nn>`; never renumbered. Native tasks are `N-nn` (cross-platform plan)                                                                                     |
| Problem    | What is wrong today, with audit IDs                                                                                                                                  |
| Pri        | **P0** blocks a core flow, fails AA, or is a foundation other tasks need · **P1** should ship in this pass · **P2** polish, may slip to [`BACKLOG.md`](./BACKLOG.md) |
| Cx         | **S** ≤ 2 files / ≤ ½ day · **M** 3–10 files · **L** > 10 files or a cross-screen refactor                                                                           |
| Model      | **Opus** — architecture, cross-screen refactors, hard UX, anything where a wrong call costs a wave · **Sonnet** — well-defined component or screen work              |
| WP         | Work package that owns the task (file ownership below). `lanes` = done by every Wave-5 lane inside its own paths                                                     |
| Acceptance | Testable: a Jest assertion, a guard count, or a named manual check                                                                                                   |

## Execution model — waves and work packages

Agents share one working tree. A work package (WP) owns a set of paths for the duration of its wave; **no agent edits a file outside its WP**. A wave starts only when the previous wave's gate is green. Phases are themes; waves are the order things actually run.

| Wave                     | Runs                                                                        | Work packages       | Gate to leave the wave                                                                                             |
| ------------------------ | --------------------------------------------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------ |

### Shared-file protocols

| Shared thing                             | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Locale catalogs `i18n/*.json`            | Only WP-6A writes them. Every other WP adds keys by creating **one** patch file `apps/app/scripts/i18n/ux-<wp>-i18n.json` (`{ "<locale>": { "dot.path": "value" } }`, all 24 locales incl. `en`, CLDR plurals for `ar`/`ru`/`bn`). At each wave gate WP-6A runs `node scripts/i18n/apply-patch-i18n.mjs`, then `pnpm --filter app test -- i18n`, then deletes the applied patches. Key namespaces are prefixed per WP feature area so two patches never define the same key |
| Tokens and primitives after Wave 2       | Frozen. A lane that needs a primitive change writes a row in the "Primitive change requests" table of the progress doc; WP-2x owners batch them between waves. Lanes never fork a primitive into a feature folder                                                                                                                                                                                                                                                           |
| `test-support/**`                        | Owned by WP-1B in Wave 1, then frozen like primitives                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `lib/library-menu.ts`, `lib/settings/**` | WP-4B in Wave 4 (`P4-11`), then WP-5F / WP-5I respectively                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Guard baseline JSON                      | Written only at wave gates (WP-3A, then WP-6C) — lanes report their counts, they do not edit the file                                                                                                                                                                                                                                                                                                                                                                       |
| `config/seo-routes.data.json`            | No new routes are planned (existing routes are kept, C-18 uses a query param). If one becomes necessary, WP-6C adds it                                                                                                                                                                                                                                                                                                                                                      |
| Git                                      | ~680 uncommitted user changes exist: snapshot-commit them before Wave 1. Agents never run `git stash`, `checkout --`, `reset` or `clean`; they stage only their owned paths (`git add <paths>`)                                                                                                                                                                                                                                                                             |
| Generated content                        | Never hand-edit `assets/data/*`, `packages/shared/src/content/*`, `lib/quran-loader.ts`                                                                                                                                                                                                                                                                                                                                                                                     |

### Definition of done (every task)

- [ ] Acceptance criteria met and recorded as evidence in the progress doc (test name, guard count, screenshot path or device note).
- [ ] `pnpm --filter app test -- <touched area>` and `pnpm check:quick` green; no new guard hits in owned paths.
- [ ] No store, repository, sync, route or SEO-metadata change unless the task says so.
- [ ] New strings only via the WP's i18n patch file; glossary and sentence case respected.
- [ ] TV: no bare numeric size in a TV branch; no double `tvDp`. RTL: logical props only.
