# Apple TV / Android TV (DS-3)

Full Munib Tracker product app on living-room devices via the [React Native TV](https://github.com/react-native-tvos/react-native-tvos) fork and Expo’s [Build for TV](https://docs.expo.dev/guides/building-for-tv/) guide.

## Approach

| Item    | Detail                                                                                  |
| ------- | --------------------------------------------------------------------------------------- |
| Package | Same `apps/app` (not a separate monorepo app)                                           |
| RN      | `"react-native": "npm:react-native-tvos@0.88.1-0"` (Expo SDK 58, React Native 0.88)     |
| Toggle  | `EXPO_TV=1` during prebuild / EAS                                                       |
| Plugin  | `@react-native-tvos/config-tv` with Leanback banner + Apple TV icons/top shelf          |
| Chrome  | Side rail always (`WideAppTabs`, overlay drawer on TV); focus rings on `PressableScale` |
| Density | Android TV / Fire TV = 960×540 dp; Apple TV = 1920×1080 pt → `TV_DENSITY` (2 on tvOS)   |

Phone ↔ TV always needs a **clean** prebuild (`pnpm prebuild:app:tv` vs `pnpm cleanbuild:app:android` / `ios`).

**Marketing semver** is unified across phone, TV, and web via [Release Please](./RELEASES.md)
(`expo` release type + `.env.example` `x-release-please-version` markers). Build /
version-code integers are **not** owned by Release Please (bump manually in
`apps/app/.env` before each store upload).

| Android TV / Fire TV | `EXPO_ANDROID_TV_APP_VERSION`           | `EXPO_ANDROID_VERSION_CODE`  |

## Commands

```bash
# Generate tvOS + Leanback native projects (always --clean)
pnpm prebuild:app:tv
pnpm prebuild:app:tv:android
pnpm prebuild:app:tv:ios
# aliases:
pnpm cleanbuild:app:tv
pnpm cleanbuild:app:tv:android
pnpm cleanbuild:app:tv:ios

# Run (after TV prebuild)
pnpm dev:app:tv:android
pnpm dev:app:tv:ios
pnpm dev:app:tv:remote <key>        # adb D-pad keys (see emulator controls below)

# Clean TV prebuild + run in one step
pnpm rebuild:app:tv:android
pnpm rebuild:app:tv:ios

# Local signed release (mirrors phone release:app:*)
pnpm release:app:android-tv          # Leanback AAB → android/play-upload/tv/
pnpm release:app:android-tv:apk      # Leanback APK (Amazon Fire TV / sideload)
pnpm release:app:android-tv:upload   # Play internal track (same package; enable TV form factor)
pnpm release:app:tvos                # tvOS IPA → ios/app-store-export-tvos/ (macOS)
pnpm release:app:tvos:upload         # altool --type appletvos
pnpm release:app:tvos:upload:validate

# EAS (profiles development_tv / preview_tv / production_tv)
pnpm build:app:android:tv
pnpm build:app:ios:tv
pnpm build:app:android:preview:tv
pnpm build:app:ios:preview:tv
pnpm submit:app:android:tv
pnpm submit:app:ios:tv

# Back to phone
pnpm cleanbuild:app:android
pnpm cleanbuild:app:ios
```

**Guards:** Phone `release:app:android` / `release:app:ios` refuse a Leanback/tvOS tree; TV release scripts refuse a phone tree. Switch with a clean prebuild.

**Artifacts**

| Command                      | Output                                            |
| ---------------------------- | ------------------------------------------------- |
| `release:app:android-tv`     | `apps/app/android/play-upload/tv/app-release.aab` |
| `release:app:android-tv:apk` | `apps/app/android/play-upload/tv/app-release.apk` |
| `release:app:tvos`           | `apps/app/ios/app-store-export-tvos/*.ipa`        |

Fire TV banner/icons stay Amazon-console-only (`firetv-*`); the APK is the Leanback binary above.

EAS profiles: `development_tv`, `preview_tv`, `production_tv` in [`apps/app/eas.json`](../apps/app/eas.json) (`env.EXPO_TV=1`). TV builds strip `extra.eas.build.experimental.ios.appExtensions` (widgets/Watch/Intents). `submit.production_tv` mirrors phone submit.

**tvOS credentials:** same bundle ID / certs as iOS, but **different provisioning profiles**. Automatic signing fails without a registered Apple TV development device — `pnpm release:app:tvos` uses **manual** signing with a `TVOS_APP_STORE` profile (`ExportOptions.tvos.plist`, override name via `TVOS_PROVISIONING_PROFILE`). When shipping both iOS and tvOS, keep tvOS credentials local (EAS-stored profiles are iOS-only).

## Android TV emulator controls

The emulator **sidebar buttons** (◁ Back · ○ Home · □ Overview) are phone navigation. On **Android TV** AVDs they often do nothing — that is expected.

**Use a remote / D-pad instead:**

1. Click the TV emulator window so it has keyboard focus.
2. Keyboard: **Arrow keys** = D-pad, **Enter** = select, **Esc** = back.
3. Or send keys via adb:

```bash
pnpm --filter app tv:remote home
pnpm --filter app tv:remote back
pnpm --filter app tv:remote up    # also: down left right select apps
```

Optional: `ANDROID_SERIAL=emulator-5554` if several devices are connected.

If the Munib splash stays forever, Metro may be unreachable — `pnpm dev:app:tv:android` now sets `REACT_NATIVE_PACKAGER_HOSTNAME=10.0.2.2` and `adb reverse` for emulators. Manually:

```bash
adb reverse tcp:8081 tcp:8081
adb shell am start -a android.intent.action.VIEW \
  -d 'exp+munib-tracker://expo-development-client/?url=http%3A%2F%2F10.0.2.2%3A8081'
```

Do **not** open the LAN IP (`192.168.x.x`) from the TV emulator — Dev Client hangs on splash, then ANRs.

`react-native.config.js` excludes widgets / quick-actions / speech-recognition / `react-native-webview` / `expo-web-browser` when `EXPO_TV=1` (needs a TV prebuild / `pod install` to drop those from Fabric codegen). Without excluding webview, `RCTThirdPartyComponentsProvider` registers `RNCWebView` with a nil Class and aborts at JS load. On tvOS, `plugins/withTvExpoModuleExcludes.cjs` also patches `use_expo_modules!(exclude: …)` because some podspecs (e.g. `expo-quick-actions`) incorrectly declare `:tvos` and would still link without that.

## Phone-only plugins (omitted when `EXPO_TV=1`)

`@bacons/apple-targets`, App Intents, external commands, Wear OS, Android widgets, `expo-quick-actions`.

**Metro (`EXPO_TV=1`):** phone-only packages resolve to stubs under `apps/app/src/lib/tv-stubs/` so imports cannot crash Leanback/tvOS JS. Covered today: `expo-speech-recognition`, `react-native-android-widget`, `expo-quick-actions`, `expo-web-browser`, `react-native-webview`, `react-native-pager-view`, `expo-notifications`, `expo-location`, `expo-sensors`, `expo-haptics`, `expo-local-authentication`, `expo-image-picker`, `expo-document-picker`, `expo-sharing`, `expo-store-review`, `expo-speech`, `expo-apple-authentication`, `expo-navigation-bar`, `expo-hinge`, `onnxruntime-react-native`.

**One exclusion list:** `apps/app/plugins/tvExcludedPackages.cjs` is the single source for phone-only native packages. `react-native.config.js` (React Native autolinking; Expo SDK 58 autolinking also honours its `null` overrides) and `plugins/withTvExpoModuleExcludes.cjs` (Podfile `use_expo_modules!(exclude: …)` + Android `expoAutolinking.exclude`) both read it — including the local `munib-tajweedformer`, `munib-wear` and `munib-external-commands` modules, which previously still linked into Android TV. `plugins/withTvNilSafeFabricComponents.cjs` also nil-safes `RCTThirdPartyComponentsProvider.mm` (via `scripts/nil-safe-fabric-third-party-components.cjs`) so any remaining unlinked Fabric Class does not abort at JS load.

**tvOS codegen must see `EXPO_TV=1`.** Xcode re-runs Fabric codegen at build time (ReactCodegen `[CP-User] Generate Specs`), so the plugin appends `export EXPO_TV=1` to `ios/.xcode.env` and hooks the nil-safe patch into that ReactCodegen phase from the Podfile `post_install` (an app-target phase runs too late — ReactCodegen has already compiled the file). `prebuild-tv.js` also runs the post-clean `pod install` with `EXPO_TV=1`. Without this, build-time codegen re-adds phone-only providers (`RNCWebView`, pager-view) and the app aborts at launch.

**AsyncStorage on tvOS:** `patches/@react-native-async-storage__async-storage@3.1.1.patch` adds a `:tvos` platform to the podspec and compiles out the `SharedAsyncStorage` path (its xcframework has no tvOS slice), so tvOS uses legacy storage under `Library/Caches` (the screenshot storage injector checks that path too).

## Density & type (Apple TV vs Android TV)

Android TV and Fire TV lay out at **960×540 dp**; Apple TV at **1920×1080 pt**. All tokens are authored in Android‑TV dp and scaled by `TV_DENSITY` ([`tv-density.ts`](../apps/app/src/constants/tv-density.ts) — `2` on tvOS, `1` everywhere else):

| Scaled automatically on tvOS                                                       | How                                                                                                                              |
| ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `Spacing`, `Radius`                                                                | `tvDp()` in [`theme.ts`](../apps/app/src/constants/theme.ts)                                                                     |
| `TvLayout` layout tokens                                                           | `tvDp()` in [`tv-layout.ts`](../apps/app/src/constants/tv-layout.ts) (font tokens stay dp)                                       |
| All `ThemedText` font metrics (incl. `fontSize` / `lineHeight` passed via `style`) | [`themed-text.tsx`](../apps/app/src/components/themed-text.tsx)                                                                  |
| Every `SymbolView` `size`                                                          | Metro aliases `expo-symbols` → [`tv-shims/expo-symbols.tsx`](../apps/app/src/lib/tv-shims/expo-symbols.tsx) (EXPO_TV + ios only) |
| Fixed sizes in `components/ui/*` primitives                                        | `tvDp()`                                                                                                                         |

Raw numeric widths/heights in screens are **not** scaled — wrap them in `tvDp()` inside TV branches when they matter. **Apple TV needs a visual QA pass on a Mac after density changes.**

TV type ramp (`TvType`, dp): body 18 · small 16 · caption 14 · label 13 · subtitle 22 · header 28 — nothing below Fire TV's 14sp floor except uppercase labels.

## Store / manifest (TV prebuild)

`app.config.js` skips permission-only config plugins on `EXPO_TV=1` (image/document picker, local-auth, location, speech recognition) and adds `blockedPermissions` for CAMERA, RECORD_AUDIO, location, biometrics and Bluetooth. Google Play treats permission-implied hardware as `required="true"` and would otherwise hide the Leanback build from most TVs. It also blocks the phone / SMS / wallpaper permissions Amazon's Fire TV test criteria (group 1) reject. `@react-native-tvos/config-tv` adds `LEANBACK_LAUNCHER`, the banner, and `touchscreen` / `faketouch` / `leanback` `required="false"`.

[`plugins/withTvAndroidManifest.cjs`](../apps/app/plugins/withTvAndroidManifest.cjs) (TV prebuild only) adds `navigation` to MainActivity `configChanges` (Bluetooth remotes / gamepads sleep and reconnect — without it the activity is recreated mid-use) and marks telephony, Bluetooth, NFC, motion sensors and portrait screen `required="false"`.

## TV home surfaces & voice search

One payload, built from the localized widget snapshot ([`tv-home-payload.ts`](../apps/app/src/lib/tv-home/tv-home-payload.ts)), feeds both platforms — no TV-only strings. `useWidgetSnapshotSync` runs on TV and calls [`syncTvHomeSurfaces`](../apps/app/src/lib/tv-home/sync.ts) instead of writing widgets. Native code: local module [`modules/munib-tv-home`](../apps/app/modules/munib-tv-home) (TV builds only — `TV_ONLY_PACKAGES` in `plugins/tvExcludedPackages.cjs` keeps it out of phone builds).

| Row (in order)       | When                       | Valid until                    |
| -------------------- | -------------------------- | ------------------------------ |
| Next Salah           | location set               | that Adhan (then the next one) |
| Ramadan              | in Ramadan                 | Suhoor / Iftar boundary        |
| Today's progress     | always                     | local midnight                 |
| Adhkar due now       | always                     | next Adhan                     |
| Friday checklist     | on Fridays                 | local midnight                 |
| Khatm / daily hadith | khatm plan / hadith loaded | — / local midnight             |

Every item has a validity window; the native side shows only what is current, so "Next Salah" stays right while the app is closed. Art: text-free 16:9 cards from `python scripts/generate-tv-home-art.py`.

### Android TV launcher row (recommendations)

- A "Munib Tracker" **preview channel** (TvProvider, `androidx.tvprovider`) — the first channel is the app's default channel and is shown without a prompt. Cards deep-link with `munib-tracker://…`.
- `TvHomeReceiver` handles `INITIALIZE_PROGRAMS` (install), `BOOT_COMPLETED` and an inexact RTC alarm at the next window boundary — no exact-alarm or wake permission.
- Permissions (TV build only): `WRITE_EPG_DATA`, `RECEIVE_BOOT_COMPLETED` — neither implies hardware.
- **Google TV home does not show app channels** — Google limits Google TV home recommendations (Engage SDK) to video apps with large audiences and excludes religious text, so this row appears on Android TV launchers that still have app channels (e.g. Nvidia Shield, many Sony / Philips / Xiaomi boxes). **Fire TV** is skipped (`isFireTV()`; its launcher has no preview channels).
- Test: `adb shell am broadcast -a android.media.tv.action.INITIALIZE_PROGRAMS -n app.munibtracker/expo.modules.munibtvhome.TvHomeReceiver`.

### Apple TV Top Shelf (opt-in)

`EXPO_TVOS_TOP_SHELF=1` + `pnpm prebuild:app:tv:ios` adds the `MunibTopShelf` app extension ([`plugins/withTvTopShelf.cjs`](../apps/app/plugins/withTvTopShelf.cjs), sources in [`tv-targets/top-shelf/`](../apps/app/tv-targets/top-shelf)) — a sectioned shelf (Today / Library) read from the App Group `group.app.munibtracker.widgets`. Items expire at their window end so tvOS reloads them. Without the flag (or without the App Group) the static Top Shelf image is shown.

Owner steps before enabling (Apple Developer):

1. Register App ID `app.munibtracker.topshelf` with the **App Groups** capability → `group.app.munibtracker.widgets`.
2. Make sure the tvOS app profile for `app.munibtracker` includes that App Group (regenerate it).
3. Create a **tvOS App Store** profile for `app.munibtracker.topshelf` (default name "Munib Tracker tvOS Top Shelf App Store", or set `TVOS_TOP_SHELF_PROVISIONING_PROFILE`).
4. `pnpm release:app:tvos` detects the extension and signs each target with its own profile (`MUNIB_TVOS_APP_PROFILE` / `MUNIB_TVOS_TOP_SHELF_PROFILE` build variables) and adds it to `ExportOptions.tvos.plist`. EAS builds need the extension's credentials too (`eas credentials`).

## Screen patterns (use these, don't reinvent)

| Need                                                                                          | Use                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Long prose / read-only cards must be scrollable by D-pad (TV scrollers are not focus targets) | [`TvReadableBlock`](../apps/app/src/components/ui/tv-readable-block.tsx) — one focus stop per paragraph/card, no zoom (`tvFocusScale={1}`). Never wrap content that already has buttons  |
| Numeric entry without typing                                                                  | `Stepper` (56dp on TV), [`tv-number-stepper.tsx`](../apps/app/src/components/tv-number-stepper.tsx), [`money/tv-number-input.tsx`](../apps/app/src/components/money/tv-number-input.tsx) |
| Horizontal chip / filter rows                                                                 | `TvFocusGuide autoFocus trapFocusLeft trapFocusRight` — **never** `trapFocusUp/Down` (blocks leaving the row)                                                                            |
| Initial focus                                                                                 | `Button preferredFocus`, `IconButton preferredFocus`, `LabeledIconButton preferredFocus`, or `hasTVPreferredFocus`                                                                       |
| Selected vs focused                                                                           | Selected = `accentSoft` fill + hairline; focus ring comes from `PressableScale`                                                                                                          |
| Long-press menus                                                                              | `ContextMenu` is a no-op on TV — expose actions as buttons/sheets                                                                                                                        |
| Blur / Liquid Glass                                                                           | `GlassSurface` renders a flat near-opaque surface on TV (perf)                                                                                                                           |
| Share, device TTS, mic, camera, file pickers, links to web                                    | Hidden on TV; web links open a QR sheet ("scan with your phone")                                                                                                                         |
| Back inside a sub-mode (expanded mini-player, hadith book)                                    | TV-only `BackHandler` listener registered while the mode is open (runs before expo-router's)                                                                                             |
| TV copy                                                                                       | `tTv(t, phoneKey, tvKey)`; strings live in [`scripts/i18n/tv-ux-i18n.json`](../apps/app/scripts/i18n/tv-ux-i18n.json) for all 24 locales                                                 |

## Layout widths (10-foot)

| Token / rule                                   | Value / behavior                                                                                                                                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TvLayout.minFocusTarget` / `minFocusTargetDp` | 64 — row / control focus target; use the unscaled `…Dp` for APIs that apply `tvDp()` themselves (e.g. `IconButton` `hitTarget`) to avoid double-scaling on tvOS                       |
| `TvLayout.contentPaddingX`                     | 48 — overscan inset on ScreenLayout / sheets / AppHeader (5% of 960dp)                                                                                                                |
| `TvLayout.overscanY`                           | 28 — top/bottom overscan (AppHeader, side rail)                                                                                                                                       |
| `TvLayout.proseMaxWidth`                       | 800 — Learn prose column                                                                                                                                                              |
| `TvLayout.gridGap`                             | 20 — tile/card gutter                                                                                                                                                                 |
| ScreenLayout default on TV                     | **Uncapped** (fills the tab pane). Learn prose routes stay at `MaxContentWidth` (800) for readability.                                                                                |
| `TvLayout.listDetailMaxWidth`                  | 1720 — Qur’an / Hadith list–detail shells                                                                                                                                             |
| `TvLayout.detailPaneMinWidth` / `MaxWidth`     | 420 / 720 — secondary panes                                                                                                                                                           |
| Selected vs focused                            | Soft fill (`accentSoft`) + hairline for **selected**; solid accent / thick ring only for **D-pad focus**. Never paint accent borders on selected rows that also receive a focus ring. |
